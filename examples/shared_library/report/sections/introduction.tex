\section{Introduction}

This report summarises the spring field survey carried out by
\orgname{} along the lower estuary reach. The survey followed the
sampling protocol set out in the station's field methods
handbook~\cite{handbook2021}, with station spacing chosen to capture
the sediment-transport gradients described in earlier
work~\cite{rivers2023}.

Three sampling campaigns were run over the season. Tide-gauge records
for the period are published as an open dataset~\cite{tidesdataset};
all timestamps in this report are referenced to that gauge.
