% tests/ctan/fixtures/, not on real CTAN) whose .sty does
% \RequirePackage{test-pkg-b}. The test target only lists test-pkg-a
% in `ctan_packages`; if the resolver works end-to-end, test-pkg-b
% is fetched transparently and the document compiles. If the
% resolver doesn't run (or the fetched files aren't reaching
% tectonic), the compile fails with
%   `! LaTeX Error: File 'test-pkg-b.sty' not found.`
%
% Why these packages don't exist on real CTAN: synthetic fixtures give
% this test a stable, minimal transitive dependency graph and keep CI
% independent of the contents and availability of CTAN mirrors.
